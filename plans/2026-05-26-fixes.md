## 1. Ghostty icon blank in alt-tab (works in launcher)  — `rebuild`

**Root cause.** Alt-tab renders icons via `ThemeIcons.iconForAppId(appId)` where
`appId` is the Hyprland window class — for Ghostty that is
`com.mitchellh.ghostty`. `iconForAppId` heuristically resolves that to the
desktop entry with id `com.mitchellh.ghostty`, which in `home.nix` is the
*hidden* override entry (`noDisplay = true`) that sets **no `icon`** — so it
falls back to the generic `application-x-executable`. The launcher works because
it lists the visible **Terminal** entry, which *does* carry
`icon = "com.mitchellh.ghostty"`.

**Change.** Give the hidden override entry an icon so appId lookups resolve to a
real icon.

- `home.nix` → `xdg.desktopEntries."com.mitchellh.ghostty"`: add
  `icon = "com.mitchellh.ghostty";`

## 4. Focus not restored after closing alt-tab / launcher  — `reload`

**Root cause.** `MainScreen` is a `WlrLayer.Top` layer surface. While a panel is
open it takes `WlrKeyboardFocus.Exclusive` (alt-tab forces it; launcher uses it
during text-input init). On close, `keyboardFocus` drops to `None`, but Hyprland
does **not** re-assert seat keyboard focus to the visually-active window — so the
window shows its active border yet receives no keystrokes.

**Change.** When the last panel closes on Hyprland, explicitly refocus the active
window.
- `Services/Compositor/HyprlandService.qml`: add `refocusActiveWindow()` →
  `Hyprland.dispatch("focuswindow address:" + Hyprland.activeToplevel.address)`
  (guarded for null).
- `Services/Compositor/CompositorService.qml`: facade `refocusActiveWindow()`.
- `Modules/MainScreen/MainScreen.qml`: a `Connections`/observer on
  `isAnyPanelOpen` falling-edge (Hyprland only) calls `refocusActiveWindow()`
  via a 0-delay `Timer`/`Qt.callLater` so it runs after `keyboardFocus` settles
  to `None`.

## 7. Audio widget lists "noctalia-qs" as a playing app  — `reload`

**Root cause.** Volume feedback plays `volume-change.wav` through a QtMultimedia
`MediaPlayer` (`SoundService`), which registers a PipeWire playback stream whose
application name is the shell itself (`noctalia-qs`). `AudioService.appStreams`
only filters nodes literally named `quickshell`, so the shell's own stream slips
through and appears in the Audio panel.

**Change.**
- `Services/Media/AudioService.qml`: add helper `isOwnStream(node)` matching
  `node.name` / `media.name` / `application.name` /
  `application.process.binary` against `{quickshell, noctalia-qs,
  noctalia-shell}`. Use it everywhere the current `=== "quickshell"` check lives
  (the `appStreams` link-group loop and the all-nodes fallback loop).

## Follow-up round 2 — 2026-05-26 (reorder reworked + drag UX)

User reorders workspaces often and wants the switch animation always correct, so
the display-only order was replaced with **physical renumbering**, and the
buggy drag was rebuilt.

**C. Reorder now physically renumbers workspaces.** Hyprland has no renumber
primitive and ties its slide-animation direction to workspace idx, so a
display-only order animated wrong. On drop, `AltTabService.applyReorder()` now
relocates every window (address-targeted `movetoworkspacesilent`, collision-proof
regardless of order) so workspace numbers match the new visual order, then
follows the focused workspace to its new number. The whole custom-order layer is
gone:
- removed `orderRank` / `persistOrder` / `moveCard` and `Settings.altTab.workspaceOrder`;
- `buildModel` / `orderedWorkspaces` sort by idx (which now *is* the user order);
- bar `Workspace.qml` reverted to plain idx sort (removed the orderRank sort +
  Settings connection);
- new backend `moveWindowToWorkspaceByAddress` (`movetoworkspacesilent
  <idx>,address:0x<addr>`) in Hyprland/CompositorService.
- Verified the API with a no-op move (`ok`, window unmoved).

**D. Drag interaction rebuilt** (`AltTabPanel.qml`). Cards are now absolutely
positioned in a track (not a Row). On grab the card shrinks (`scale 0.86`) and
glues to the cursor; the others slide to make room (`Behavior on x` as the slot
order updates live); on release it animates back to full size in its new slot.
The model swap is deferred ~180ms (`finalizeTimer`) so the drop animation isn't
cut off, while entry id/idx/name are mutated immediately so a commit during that
window still targets the right workspace.

Caveat now resolved: switch animation is always correct because idx order ==
visual order at all times.

All hot-reloaded clean. Interactive drag feel + the renumber need on-device
testing.
